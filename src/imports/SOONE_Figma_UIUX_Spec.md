# SO’ONE 소원컴퍼니 웹앱 Figma UI/UX 설계서

> 이 문서는 SO’ONE(소원컴퍼니)의 샤쉐·디퓨저·홈 프래그런스 쇼핑몰을 Figma로 설계하기 위한 실무 기준서다. 이솝의 에디토리얼 커머스 구조를 참고하되, 로고·카피·이미지·화면을 복제하지 않고 SO’ONE 고유의 ‘향과 기억’ 경험으로 재구성한다.

---

## 0. 프로젝트 개요

### 브랜드 표기

- 정식 회사명: **소원컴퍼니**
- 소비자 브랜드명: **SO’ONE**
- 권장 영문 표기: `SO’ONE`
- 보조 표기: `소원컴퍼니`
- 로고 문장 예시: `SO’ONE — Scents remain.`

### 브랜드 핵심 문장

> 향은 보이지 않지만,  
> 공간의 인상과 그날의 기억을 오래 남깁니다.

### 브랜드 의미 제안

`SO’ONE`은 ‘누군가를 위한 향’, ‘하나의 공간’, ‘소원처럼 오래 남는 기억’을 함께 연상시키는 이름으로 사용한다.

### 사업 목표

1. 개인 고객에게 샤쉐·디퓨저·룸 스프레이·향기 오브제를 판매한다.
2. 기업·기관의 로고, 문구, 패키지를 적용한 맞춤 굿즈를 제작한다.
3. 향을 상품이 아니라 공간과 기억을 설계하는 경험으로 보여준다.
4. 모바일 웹앱을 중심으로 탐색, 추천, 구매, 재구매까지 연결한다.
5. 카페24의 상품·회원·쿠폰·리뷰·주문·배송 기능과 연결한다.

### 핵심 사용자

| 사용자 | 목적 | 필요한 경험 |
|---|---|---|
| 개인 구매자 | 집·차량·옷장에 둘 향 구매 | 공간별 추천, 향 설명, 쉬운 구매 |
| 선물 구매자 | 감성적인 선물 선택 | 선물 목적, 포장, 메시지 카드 |
| 기업 담당자 | 굿즈·행사 기념품 제작 | 최소 수량, 견적, 시안, 납기 안내 |
| 재구매 고객 | 기존 향 재주문 | 최근 구매, 빠른 담기, 정기 알림 |
| 관리자 | 상품과 콘텐츠 운영 | 카페24 관리 및 별도 콘텐츠 관리 |

## 1. UX 콘셉트

### 핵심 방향: Editorial Commerce

SO’ONE은 상품 목록부터 보여주는 일반 쇼핑몰이 아니라 다음 순서로 경험을 설계한다.

1. 공간과 향의 분위기를 영상·사진으로 경험한다.
2. 향을 만드는 원료와 기억에 대한 이야기를 읽는다.
3. 자신의 공간과 목적에 맞는 향을 탐색한다.
4. 관련 상품을 발견하고 구매한다.
5. 사용 후 리뷰, 재구매, 선물 및 기업 주문으로 확장한다.

### 콘텐츠와 커머스 비율

- 메인 홈페이지: 브랜드·에디토리얼 60% / 상품·구매 40%
- 카테고리 페이지: 에디토리얼 35% / 상품·탐색 65%
- 상품 상세페이지: 제품 경험 45% / 정보·구매 55%
- 기업 굿즈 페이지: 신뢰·사례 50% / 상담 전환 50%

### 피해야 할 표현

- 과도한 연기·향기 입자 애니메이션
- 모든 문구에 명조체 사용
- 카드마다 그림자와 둥근 모서리 적용
- 강한 그라데이션과 네온 컬러
- 작은 글씨로 고급스러움을 표현하는 방식
- 이솝 로고·상품 배치·카피·사진의 직접 복제

## 6. 메인 홈페이지 프레임 명세

Figma 프레임 이름:

- `D-01_Home_Default_1440`
- `M-01_Home_Default_390`

### 6.1 프로모션 바

- Desktop 높이: 40px
- Mobile 높이: 36~44px
- 배경: `Color/Surface/Dark`
- 중앙 정렬 한 줄
- 공지 최대 3개 자동 전환
- 닫기 버튼 제공

문구 예시:

- 첫 구매 고객 10% 혜택
- 50개부터 시작하는 기업 맞춤 샤쉐
- 5만원 이상 구매 시 무료배송

### 6.2 헤더

Desktop:

- 전체 높이: 약 128px
- 1행: 왼쪽 기업 제작 문의 / 중앙 SO’ONE / 오른쪽 검색·마이·장바구니
- 2행: 주요 카테고리 중앙 정렬
- 히어로 위에서는 투명, 스크롤 후 크림 배경

Mobile:

- 높이: 60px
- 왼쪽 메뉴 / 중앙 로고 / 오른쪽 검색·장바구니
- 메뉴 클릭 시 전체 화면 드로어

### 6.3 영상 히어로

- Desktop 높이: 760~820px
- Mobile 높이: 75~85svh
- 미디어: 무음 자동 재생 영상 또는 고해상도 이미지
- 오버레이: 하단 중심 `rgba(0,0,0,0.38)` 그라데이션
- 텍스트 최대 폭: Desktop 720px / Mobile 330px
- 카피는 중앙 하단 또는 좌측 하단

정확한 메인 카피:

> 향은 보이지 않지만,  
> 공간의 인상과 그날의 기억을 오래 남깁니다.

CTA:

- Primary: `향을 만나보기`
- Secondary: `나에게 맞는 향 찾기`

컨트롤:

- 재생·일시정지
- 음소거
- 이전·다음
- 슬라이드 진행 표시

### 6.4 브랜드 선언 섹션

- 크림 배경
- 화면 중앙의 큰 명조 문장
- 최대 폭 900px
- Desktop 상하 160px / Mobile 96px
- `공간의 인상`, `그날의 기억`만 Accent/Memory 색상

### 6.5 50:50 원료·대표 상품 섹션

Desktop:

- 전체 높이: 약 1100~1400px
- 왼쪽 이미지 패널: 50%, sticky 가능
- 오른쪽 콘텐츠: 50%
- 스크롤 순서: 원료 설명 → 제품 등장 → 향 노트 → 가격 → 구매

Mobile:

- 이미지 → 문장 → 상품 이미지 → 구매 정보 순서
- sticky 효과 제거 또는 짧게 제한

SO’ONE 콘텐츠 예:

- 왼쪽: 한지와 면직물의 질감
- 제목: `향을 머금는 소재`
- 설명: 샤쉐가 향을 저장하고 천천히 공간에 남기는 과정
- 오른쪽: 대표 샤쉐 상품 및 바로 담기

### 6.6 공간별 향 추천

제목: `어떤 공간에 향을 남기고 싶나요?`

카테고리:

- 현관
- 침실
- 옷장
- 차량
- 업무 공간
- 선물

Desktop: 비대칭 3열 이미지 그리드  
Mobile: 가로 스크롤 카드, 다음 카드 20% 노출

### 6.7 대표 컬렉션 60:40

교차 배치 섹션 3개:

1. `옷장에 남는 깨끗한 향`
2. `잠들기 전, 낮아지는 향`
3. `처음 들어선 공간의 기억`

- 이미지 60 / 텍스트 40
- 다음 섹션은 좌우 반전
- CTA: `컬렉션 보기`

### 6.8 추천 상품 레일

- 제목: `공간에 오래 머무는 향`
- Desktop 3열 또는 4열
- Tablet 2열
- Mobile 1.15개 가로 스크롤
- 옵션을 선택하면 카드 안에서 바로 장바구니 추가

### 6.9 향기 파인더

- 질문형 추천 웹앱 진입 구간
- 분위기 이미지와 설명을 50:50 배치
- CTA: `나의 향 찾기`
- 예상 소요 시간: `약 1분`

### 6.10 기업 굿즈 섹션

- 제목: `브랜드의 기억을 향으로 남깁니다`
- 실제 제작 사례 또는 패키지 목업
- 핵심 정보: 최소 수량 / 제작 기간 / 로고·문구 / 패키지 선택
- CTA 1: `제작 사례 보기`
- CTA 2: `견적 문의하기`

### 6.11 공식몰 서비스

- 이미지 60 / 텍스트 40
- 선물 포장, 메시지 카드, 샘플, 기업 상담 설명
- CTA: `SO’ONE의 선물 서비스`

### 6.12 향의 기록

카드 3개:

- 향과 기억
- 공간과 향
- 샤쉐를 오래 사용하는 방법

각 카드 표시 정보:

- 콘텐츠 유형
- 제목
- 1줄 설명
- 읽기 시간

### 6.13 혜택 바와 푸터

혜택 4개:

- 무료배송
- 안전결제
- 향 샘플
- 선물 포장

푸터 메뉴:

- 고객 지원
- 쇼핑 안내
- 기업 주문
- 브랜드
- 정책 및 사업자 정보
- SNS

## 12. 모션 및 프로토타입 명세

### Motion Tokens

| 토큰 | 값 | 용도 |
|---|---:|---|
| `Motion/Fast` | 200ms | 버튼·아이콘 |
| `Motion/Base` | 400ms | 메뉴·카드 |
| `Motion/Slow` | 700ms | 이미지·섹션 전환 |
| `Motion/Hero` | 900ms | 히어로 크로스페이드 |
| `Ease/Out` | `cubic-bezier(.22,1,.36,1)` | 등장 |
| `Ease/InOut` | `cubic-bezier(.65,0,.35,1)` | 상태 전환 |

### 주요 프로토타입

1. 히어로 2개 슬라이드 자동 전환
2. 메가 메뉴 Open/Close
3. 헤더 투명 → 크림 배경 전환
4. 50:50 섹션 스크롤 리빌
5. 상품 이미지 Hover crossfade
6. Quick Add 옵션 열기
7. 향기 파인더 질문 전환
8. 모바일 필터 Bottom Sheet
9. 모바일 PDP 하단 구매 바
10. 기업 견적 폼 단계 전환

### 스크롤 등장 규칙

- 시작: opacity 0, translateY 24px
- 종료: opacity 1, translateY 0
- duration: 500~700ms
- 한 화면에서 최대 3개 요소만 순차 등장
- stagger: 80~120ms
- `prefers-reduced-motion`에서 이동 제거, 단순 표시

- 색상만으로 상태를 구분하지 않음

## 16. 이미지 아트 디렉션

### 필요한 이미지 유형

1. 공간 속 제품
2. 패브릭·종이·나무의 질감
3. 원료 클로즈업
4. 빛과 그림자가 있는 정물
5. 제품 누끼
6. 선물 포장 과정
7. 기업 맞춤 패키지 사례
8. 사용 장면의 짧은 영상

### 촬영 원칙

- 색 온도는 따뜻하게 유지하되 과도한 노란색 금지
- 인공적인 연기보다 패브릭 움직임과 자연광 활용
- 배경 소품은 3~5개 이내
- 제품 라벨이 모든 사진에서 정면일 필요는 없음
- 여백이 있는 가로·세로 버전을 동시에 촬영

### Figma 이미지 비율

- Hero: 16:9 Desktop / 4:5 Mobile
- Split image: 4:5 또는 3:4
- Category card: 4:5
- Product: 1:1 또는 4:5
- Editorial: 3:2
- Corporate case: 4:3
